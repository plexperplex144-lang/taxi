# Доход таксиста

PWA-приложение для учёта доходов и расходов таксиста за смену. Дизайн — в стиле Яндекс Go.

## Возможности

- Учёт доходов (нал / безнал / чаевые) и расходов по категориям (заправка, мойка, еда, ремонт, расходники, аренда)
- Заправка — режим «цена за литр × литраж» или простая сумма (переключается в настройках)
- Итоги по дням / неделе / месяцу, разбивка по категориям
- Светлая / тёмная / системная тема
- Экспорт и импорт истории в файл `.json` (перенос между телефонами, бэкап)
- Работает офлайн после первого открытия (service worker)
- Устанавливается на домашний экран как приложение (Android / iOS)

## Хранение данных

Все данные хранятся локально в `localStorage` браузера на устройстве пользователя. Бэкенда и серверного хранения нет — для переноса на другое устройство используйте экспорт/импорт в настройках приложения.

## Структура

```
index.html               — приложение (вся логика)
manifest.json             — манифест PWA
icon-192.png               — иконка 192×192
icon-512.png                — иконка 512×512
icon-512-maskable.png        — маскируемая иконка (Android adaptive icon)
sw.js                          — service worker (офлайн-кеш)
```

## Деплой на GitHub Pages

1. Залить все файлы этого репозитория в корень ветки `main`
2. В репозитории: **Settings → Pages → Source** → выбрать ветку `main`, папку `/ (root)`
3. Через минуту-две сайт будет доступен по адресу `https://<username>.github.io/<repo>/`
4. Открыть этот адрес на телефоне и установить через «Добавить на экран Домой» (Android/iOS)

GitHub Pages отдаёт сайт по HTTPS автоматически — это обязательное условие для работы service worker и полноценной установки PWA.

## Локальная разработка

Файл можно открывать напрямую (`file://`), но тогда service worker не зарегистрируется (требует HTTPS или localhost). Для локального сервера подойдёт, например:

```bash
python3 -m http.server 8000
```

и открыть `http://localhost:8000`.
